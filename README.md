# QuickCalc

A modern calculator web app (Flask + vanilla JS).

## Run (Windows)

Double-click **start.bat**.

First run creates a `.venv` and installs requirements; then it starts the server and opens http://127.0.0.1:5000 in your browser. Close the console window to stop the server.

## Run (manual)

```bash
python -m pip install -r requirements.txt
python app.py
```

## Tests

```bash
python -m pytest -q
```
